HR Prompt Generator

เครื่องมืออำนวยความสะดวกในการสร้าง Prompt สำหรับให้ AI ช่วยร่าง หลักการและเหตุผล สำหรับโครงการด้านการบริหารและพัฒนาทรัพยากรบุคคล ที่เชื่อมโยงกับทิศทางขององค์กร

ข้อมูลโครงการ (งานบุคคล)

กรอกข้อมูลเบื้องต้นเพื่อใช้เป็นฐานข้อมูลในการสร้าง Prompt

คำแนะนำ: กรุณาระบุชื่อโครงการ หรือ วัตถุประสงค์ เพื่อให้ระบบเขียน Prompt ได้อย่างสมบูรณ์ที่สุด

ผลลัพธ์โครงสร้างคำสั่ง

คัดลอกข้อความไปวางลงใน ChatGPT, Claude หรือ Gemini

พร้อมช่วยเหลือคุณสร้างสรรค์โครงการด้านบุคลากร

กรอกรายละเอียดและยุทธศาสตร์ส่วนงานเพื่อสร้าง Prompt ได้ทันที

แนะนำเพิ่มเติมสำหรับผู้ใช้

เมื่อนำ Prompt นี้ไปส่งต่อให้ AI คุณจะได้รับแบบร่าง "หลักการและเหตุผล" ที่อิงกับทฤษฎีการบริหารงานบุคคล (HR) หากต้องการเน้นเรื่องเฉพาะเจาะจง เช่น "เน้นเรื่อง Work-Life Balance" หรือ "การปรับตัวสู่ดิจิทัล (Digital Transformation)" สามารถพิมพ์สั่ง AI เพิ่มเติมได้เลยครับ
